# PND-PsySHAP

PND-PsySHAP is a Windows desktop executable for identifying psychosocial risk factors for prenatal depression in pregnant women using machine learning and SHAP-based explanation.

## Thesis Title

Identification of Psychosocial Risk Factors for Prenatal Depression in Pregnant Women Based on Machine Learning and the SHAP Method
